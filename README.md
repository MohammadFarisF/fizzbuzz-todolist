# Technical Test - Programmer Staff

- Tugas 1 (FizzBuzz): Menampilkan urutan angka 1 sampai 100 dengan aturan kelipatan 3 (`Fizz`), kelipatan 5 (`Buzz`), dan kelipatan 3 & 5 (`FizzBuzz`).
- Tugas 2 (Todo App): Aplikasi pencatat tugas dengan fitur CRUD (tambah, lihat, edit, tandai selesai, dan hapus).

# Teknologi yang Digunakan

- React 18
- TypeScript
- Vite
- CSS

# Cara Menjalankan di Lokal

Pastikan Node.js sudah terinstal di komputer Anda.

1. Clone repositori ini:
   git clone [https://github.com/MohammadFarisF/fizzbuzz-todolist.git](https://github.com/MohammadFarisF/fizzbuzz-todolist.git)
2. Masuk ke direktori proyek:
   cd fizzbuzz-todolist
3. Instal dependensi:
   npm install
4. Jalankan:
   npm run dev
